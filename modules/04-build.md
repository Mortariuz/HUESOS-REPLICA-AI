# BUILD — implementación de interfaz y producto

**Entrada:** arquitectura, especificaciones visuales y matriz de funciones.

1. Inspecciona el repositorio antes de modificarlo.
2. Identifica framework, estructura, scripts, pruebas y convenciones.
3. Propón plan de cambios y evita reescrituras innecesarias.
4. Implementa primero shell, navegación y un flujo principal completo.
5. Construye pantalla por pantalla, incluyendo carga, vacío, error y éxito.
6. Mantén componentes reutilizables, tipado, accesibilidad y responsive.
7. Ejecuta lint, build y pruebas disponibles; informa resultados reales.
8. Documenta archivos modificados y cómo ejecutar localmente.

No sobrescribas archivos ni hagas commits, push o deploy sin autorización explícita.
