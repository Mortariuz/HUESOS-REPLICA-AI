# TEST — calidad y corrección

**Entrada:** requisitos, flujos, repositorio y entorno de prueba.

- Convierte cada MUST en criterios verificables.
- Cubre pruebas unitarias, integración, E2E, accesibilidad, responsive y seguridad según alcance.
- Prioriza casos felices, validaciones, permisos, errores de red, datos vacíos y concurrencia.
- Ejecuta pruebas disponibles con herramientas autorizadas.
- Registra pasos para reproducir, esperado, obtenido, severidad y evidencia.
- Corrige bloqueantes y críticos primero; vuelve a ejecutar regresión.

**Entregables:** `test-plan.md`, `bug-report.md`, `test-results.md`. No declares aprobada una prueba que no se ejecutó.
