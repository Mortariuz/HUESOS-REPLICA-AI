# HUESOS REPLICA AI — edición para ChatGPT

Adaptación independiente del flujo de `replica-skill` para trabajar con ChatGPT, GPTs personalizados y Proyectos. No instala comandos `/` automáticamente.

## Función
Flujo de 11 fases: RECON, ARCHITECT, DESIGN, BUILD, BACKEND, TEST, DIFF, MARKET, BRAND, LAUNCH y DEPLOY.

## Instalación
1. Crea un Proyecto de ChatGPT llamado **HUESOS REPLICA AI**.
2. Copia `HUESOS_REPLICA_MASTER.md` en las instrucciones del Proyecto.
3. Adjunta los archivos de `modules/` y `templates/` como referencia.
4. Inicia con: `Iniciar réplica: [URL o descripción]`.

También puedes usarlo en un GPT personalizado (si está disponible) o adjuntar el archivo maestro en un chat normal.

## Atajos conversacionales
- `RECON`: pantallas, flujos y funciones.
- `ARCHITECT`: stack, datos, API y seguridad.
- `DESIGN`: sistema visual original.
- `BUILD`: implementación por etapas.
- `BACKEND`: servicios e integraciones.
- `TEST`: pruebas y corrección.
- `DIFF`: comparación y paridad.
- `MARKET`: mercado y comentarios públicos verificables.
- `BRAND`: identidad diferenciada.
- `LAUNCH`: preparación de lanzamiento.
- `DEPLOY`: publicación y operación con autorización.
- `ESTADO`: avances y bloqueos.

## Principios
Clean-room; no copiar código, marca, activos, textos ni APIs privadas. Distinguir evidencia de inferencias. No inventar resultados. Inspeccionar antes de modificar. No sobrescribir, hacer push, borrar, gastar o desplegar sin autorización explícita. No declarar pruebas o despliegues que no se hayan ejecutado.

## Expediente recomendado
Mantén los resultados en `replica/`: reconocimiento, matriz de funciones, arquitectura, diseño, plan de construcción, backend, pruebas, bugs, paridad, mercado, marca, lanzamiento y despliegue.

ChatGPT no garantiza que los archivos sigan disponibles entre conversaciones: conserva los entregables en el Proyecto o vuelve a adjuntarlos.
